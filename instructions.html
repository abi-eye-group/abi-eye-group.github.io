Stimulus display instructions

Using the displays

  1. Open the gratings display (or the moving Gabor patch) in Chrome.
  2. Press Press here to enter experiment. The page goes full screen and the stimulus starts, with the controller at the top right.
  3. Set the Display Options (below) first, so sizes and speeds are in true degrees at your viewing distance.
  4. Change the stimulus and its parameters with the controller. Changes apply when you release a control.
  5. Press Esc to leave full screen.

A link can choose the stimulus directly: gratings.html?stimulus=disks|bars|sinusoids, and for disks &sweep=1 or &sweep=0.

Controller Options

The control panel has the following options:



Main
Stimulus
[ default: disks ] Stimulus choices e.g. "disks" | "bars" | "sinusoids"
logMAR
[ default: 1.0 logMAR ] logMAR specification is: 1) disks: angular size of central disk, 2) bars: stripe width, 3) sinusoids: wavelength/2
Speed
[ default: 2.5 deg/sec ] Horizontal drift speed for stimulus
Direction
[ default: left ] Horizontal drift direction.
Distance
[ default: 100 cm ] Distance of the observer from the display
Sweep
[ default: true ] Only visible when stimulus is "disks". Overrides the "logMAR" controller when enabled.


Sweep
Only visible when stimulus is "disks".

Step Duration
[ default: 0.5 sec ] Time spent per logMAR level
Step Size
[ fixed: 0.1 logMAR ] Size of each step (not in the controller)

Tips

  • The demonstrations work best in Chrome.
  • Motion artefacts (comet tails) are typical on LED monitors; blur reduction helps. We have used nVidia Ultra Low Motion Blur (ULMB), and a high refresh rate OLED tablet gave artefact-free motion.
  • screenresolutiontest.com reports a screen's pixel size.
